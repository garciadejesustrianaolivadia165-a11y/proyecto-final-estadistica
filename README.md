## 🎯 Problema  
Analizar y predecir el salario en función de distintas características laborales y personales, con el fin de identificar los factores que más influyen en su variación.

## 📊 Variables  
Se consideran variables como años de experiencia, nivel educativo, tipo de empleo, industria, ubicación y habilidades.  
Estas actúan como variables independientes, mientras que el salario es la variable dependiente.

## 🔍 Análisis  
Se realizará un análisis exploratorio de datos (EDA) para comprender la distribución y relaciones entre variables, seguido de un análisis de correlación.
